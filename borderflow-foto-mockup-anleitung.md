# BorderFlow Foto-Mockup: Schritt-für-Schritt-Anleitung

## 🎯 Empfohlenes Foto-Konzept für LinkedIn-Post

**"Der QR-Code im Fokus"** – Professionell, modern, story-telling

---

## Variante A: Mit Canva (einfach, 15 Minuten)

### Schritt 1: Template auswählen
1. Gehen Sie zu **canva.com**
2. Wählen Sie **"LinkedIn Post"** (1080 x 1080 px)
3. Suchen Sie nach Template: **"App Mockup"** oder **"Phone in Hand"**

### Schritt 2: Hintergrund gestalten
**Option 1: LKW-Foto als Hintergrund**
- Unsplash/Pexels durchsuchen: "truck highway austria" oder "logistics alpine"
- Foto hochladen und als Hintergrund setzen
- **Wichtig:** Leicht verschwommen/Unschärfe hinzufügen (Canva: Effekte → Blur)
- Transparenz: 70-80% (damit der Fokus auf dem Smartphone bleibt)

**Option 2: Gradient-Hintergrund**
- Farbverlauf: Dunkelblau (#0A2E4D) → Hellblau (#4A90E2)
- Moderne, cleane Optik
- Subtile Textur oder Raster-Muster

### Schritt 3: Smartphone-Mockup einfügen
1. In Canva suchen: **"iPhone Mockup"**
2. Smartphone-Element auf Canvas ziehen
3. Position: **Leicht versetzt in die Mitte** (nicht exakt zentral)
4. Größe: Ca. 40-50% der Bildgröße
5. Neigung: **Leicht schräg** (ca. 10-15°) für Dynamik

### Schritt 4: App-Screenshot erstellen

**Option A: Eigener Screenshot (wenn BorderFlow-App existiert)**
- Screenshot der BorderFlow-WebApp machen
- In Canva hochladen
- In das Smartphone-Mockup einfügen

**Option B: Fake-Mockup erstellen (wenn noch kein UI existiert)**

**Smartphone-Display-Inhalt:**

```
┌─────────────────────────┐
│  ← BorderFlow      ☰   │ (Header)
├─────────────────────────┤
│                         │
│  🎯 Ihr Ziel:          │
│  Warenort Hohenems     │
│                         │
│  📍 Entfernung: 2.3 km │
│  ⏱️ Ankunft: 5 Min.    │
│                         │
│  [═══════════50%═══]   │ (Fortschrittsbalke)
│                         │
│  ┌─────────────────┐   │
│  │                 │   │
│  │   [Mini-Karte]  │   │ (Google Maps-Style)
│  │                 │   │
│  └─────────────────┘   │
│                         │
│  ┌─────────────────┐   │
│  │ Route starten 🚛│   │ (Grüner Button)
│  └─────────────────┘   │
│                         │
│  🌍 Sprache: Deutsch ▼ │
│                         │
└─────────────────────────┘
```

**In Canva umsetzen:**
1. Rechteck für Smartphone-Display
2. Text-Elemente für "Warenort Hohenems" etc.
3. Icons einfügen (🎯📍⏱️🌍)
4. Button mit grünem Hintergrund (#00C853)
5. Mini-Karte als Bild einfügen (Screenshot von Google Maps oder Icon)

### Schritt 5: QR-Code hinzufügen (optional, aber empfohlen!)

**QR-Code erstellen:**
1. Gehen Sie zu **qr-code-generator.com**
2. URL eingeben: `https://www.logistikberater.at/vlb-borderflow.html`
3. Design anpassen (Farbe: BorderFlow-Blau)
4. QR-Code herunterladen (PNG, hohe Auflösung)

**In Canva platzieren:**
- Position: **Unten rechts** oder **oben links** im Bild
- Größe: Klein, aber scannbar (ca. 200 x 200 px im Endbild)
- Weißer Hintergrund-Kasten für Kontrast
- Optional: Text darunter "Jetzt testen →"

### Schritt 6: Text-Overlays hinzufügen

**Hauptüberschrift (groß, auffällig):**
```
📱 Ein Scan. Alle Infos.
```

- Position: Oben links oder oben mittig
- Schriftart: **Montserrat Bold** oder **Roboto Bold**
- Schriftgröße: 64-80 pt
- Farbe: Weiß mit schwarzem Schatten (für Lesbarkeit)

**Subline (kleiner, beschreibend):**
```
BorderFlow – Digitale Fahrerkommunikation für Smart Border Austria
```

- Position: Unter der Hauptüberschrift
- Schriftart: **Montserrat Regular** oder **Open Sans**
- Schriftgröße: 28-36 pt
- Farbe: Hellgrau oder Weiß (70% Opacity)

**Logo/Branding:**
- Position: Unten links
- Ihr Firmenlogo oder "BorderFlow"-Schriftzug
- Größe: Klein, nicht dominant

### Schritt 7: Visuelle Akzente

**Icons für Storytelling:**
- **Position 1 (links oben):** 📱 QR-Code-Icon
- **Position 2 (rechts):** 🚛 LKW-Icon
- **Position 3 (unten):** ✅ Checkmark

→ Diese als "Flow" anordnen mit Pfeilen dazwischen (→ → →)

**Alternative:** Drei kleine Kreise mit Icons:
```
📱 → 🗺️ → ✅
Scannen  Route  Fertig
```

### Schritt 8: Feinschliff

✅ **Kontraste prüfen** – Ist Text gut lesbar?  
✅ **Farbharmonie** – Passen alle Farben zusammen?  
✅ **Weißraum** – Nicht zu vollgepackt?  
✅ **Mobile Preview** – Wirkt es auf Smartphone-Ansicht?  

### Schritt 9: Export
- Format: **PNG** (bessere Qualität für LinkedIn)
- Auflösung: **1080 x 1080 px** (Square) oder **1200 x 627 px** (Landscape)
- Download und auf LinkedIn hochladen

## Variante C: Mit echtem Foto (professionell)

Falls Sie ein **echtes Foto-Shooting** machen möchten:

### Was Sie brauchen:
- 📱 Smartphone (möglichst modernes Modell)
- 🚛 LKW im Hintergrund
- 👤 Fahrer oder Modell (Hand im Vordergrund)
- 📷 Gute Kamera (Smartphone-Kamera reicht oft)
- 🌄 Location: Grenzübergang, Logistikzentrum oder Bergkulisse

### Shooting-Anleitung:

**1. Setup:**
- Fahrer hält Smartphone in der Hand
- Smartphone zeigt BorderFlow-App (oder Mockup-Screenshot)
- LKW im Hintergrund (3-5 Meter Abstand)
- Tageszeit: Morgens oder spätnachmittags (goldene Stunde)

**2. Kameraeinstellungen:**
- **Modus:** Portrait-Modus (für Unschärfe im Hintergrund)
- **Fokus:** Auf Smartphone-Display
- **Belichtung:** Leicht überbelichtet (Display gut sichtbar)

**3. Perspektive:**
- Kamera auf Augenhöhe oder leicht von oben
- Smartphone leicht schräg halten (nicht frontal)
- Hand natürlich, nicht verkrampft

**4. Post-Processing:**
- Helligkeit erhöhen (Display muss lesbar sein)
- Kontrast leicht erhöhen
- Hintergrund leicht entsättigen (Fokus auf Smartphone)
- Optional: Vignette hinzufügen (dunkle Ränder)

**Apps für Bearbeitung:**
- **Snapseed** (kostenlos, professionell)
- **Lightroom Mobile** (Adobe)
- **VSCO** (Filter und Bearbeitung)
